计数题的共同焦虑是"重了还是漏了"。三道比赛题对应三个方向：**正难则反数补集**、**枚举贡献定边界**、**换统计对象拆贡献**。

## 一、好串计数（牛客周赛 144 B）

> **题意**（[牛客周赛 144](https://ac.nowcoder.com/acm/contest/134981) B）：长度为 3 的子串若**至少含两种不同字符**则称为好串。统计 s 的好串子串数量。

"至少两种"的反面是"全相同"。总数好算，反面也好算，直接容斥：

```cpp
// 答案 = 所有长度3子串数 - 全相同字符的子串数
ans = n*(n-1)/2 ... 对连续段：Σ len·(len-1)/2 取补
```

具体地，把 s 切成极长同字符段，每段内部长度 3 的子串全同（贡献 C(len,2) 按滑窗计），用总数减掉即可（样例 `1101 → 5` 可验证）。**核心**："至少 / 恰好"类计数，先看补集是不是平凡很多。

## 二、最大值恰等于区间长度（苯环杯 F）

> **题意**（["⌬杯"蓝桥杯省赛模拟赛](https://ac.nowcoder.com/acm/contest/130222) F）：统计有多少个子数组，其**最大值恰好等于区间长度**。

按"枚举谁当最大值"来拆：对每个位置 p（值为 k = a[p]），用**单调栈**求出 p 作为最大值能管辖的左右边界 (L, R]（左右侧最近更大元素夹逼，重复值用严格/非严格错开防重）。于是问题变成：在 p 的管辖范围内，数**长度恰为 k** 且必须覆盖 p 的区间个数——左右端点的合法范围是一段连续区间，直接相乘：

```cpp
// 长度 k、覆盖 p：左端点 ∈ [max(L+1, p-k+1), min(p, R-k)]，个数 = max(0, 范围长度)
```

O(n) 扫完所有位置。**核心**：等值条件（max = len）把"区间"和"值"锁死在一起，枚举值定区间长，单调栈定管辖边界——两个经典组件一次拼装。

## 三、刷色后的美丽度总和（洛谷蓝桥省赛模拟 G）

> **题意**（[洛谷蓝桥杯省赛模拟赛 2026](https://www.luogu.com.cn/contest/314564) G）：数组的美丽度 = 极长同色段数。对每个区间 [l, r] 和每种颜色 k，把 [l, r] 全刷成 k 后数组有一个美丽度；对所有"区间 × 颜色"组合求美丽度总和。

区间 O(n²) 个、颜色 O(m) 种，逐个算必然爆炸。**拆贡献到"段"**：刷色只改变 [l, r] 内部与两个接缝处的分段结构——

- 区间外部的段数与 k 无关：用前缀/后缀美丽度乘上端点组合数，得到**基础项 BASE**；
- 区间内部刷成同色：恒为 1 段；
- 接缝处：若 l-1 位置颜色恰为 k，并掉左接缝（-1）；右接缝同理。

于是总答案 = Σ(区间) [BASE(l,r) + 1 − 并左 − 并右]，而"颜色恰为 k 的接缝"按颜色把位置分桶统计，整体 O(n + m)。

**核心**：多对象求和（区间 × 颜色）时，别算每个组合的值，而是**让每个"最小单元"（这里是段和接缝）报告它被计了多少次**。这就是贡献法的本质。

## 四、所有子数组的不同值之和（牛客寒假营 2 H）

> **题意**（[牛客寒假营 2](https://ac.nowcoder.com/acm/contest/120562) H）：对每个子数组数一遍"不同值的个数"，把这些个数加起来。

双重循环枚举子数组再数 distinct 是 O(n²·n)。贡献法翻转视角：**每个"值的一次出现"贡献多少个子数组**——枚举右端点 i，维护 `last[x]`（值 x 上次出现的位置），以 i 结尾的子数组里 x 被计入的个数是 `i − last[x]`：

```cpp
for (int i = 1; i <= n; i++) {
    S += i - last[a[i]];   // 递推后 S 恰 = 以 i 结尾的所有子数组 distinct 总数
    last[a[i]] = i;
    ans += S;              // 答案 = Σ_i S_i
}
```

为什么这个递推对：从 i−1 到 i，每个子数组 [left, i] 比它去掉 a[i] 后多出的 distinct，恰好来自"a[i] 在 [left, i−1] 中没出现过"的那些 left，共 `i − last[a[i]]` 个。**核心**："数每个子数组里有几个不同值" ↔ "数每个出现被几个子数组包含"，交换求和顺序后哈希表 O(n) 收工。

## 小结

| 题 | 方向 | 一句话 |
|---|---|---|
| 周赛144 B 好串 | 补集 | "至少"反面常常平凡 |
| 苯环杯 F 最大值=长度 | 定界 | 枚举最大值，单调栈给管辖范围 |
| 省模拟 G 美丽度 | 拆贡献 | 让最小单元报告被计次数 |
| 寒假营2 H 不同值之和 | 换求和顺序 | 每次出现贡献 i − last[x] 个子数组 |

计数题拿到手先做一个"会计检查"：总数分给谁？每个单元被数几次？重漏往往在草稿纸上就现形。相关阅读：[前缀和的竞赛应用](./2026-08-16-prefix-sum-contest-apps)（回文子序列计数）。
