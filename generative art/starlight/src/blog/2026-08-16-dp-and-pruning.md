## 一、划段 DP + 单调队列（蓝桥杯多校模拟赛二 G）

> **题意**（[蓝桥杯多校模拟赛（第二场）](https://ac.nowcoder.com/acm/contest/132303) G）：把字符串切成若干段，每段长度 ≤ k 且**必须含至少一对相邻相同字符**，求最少段数。

先做两个预处理把"合法段"变成 O(1) 判定：

- `pr[i]`：位置 ≤ i 处最近的"相邻相同对"的位置（s[j] == s[j+1] 的最大 j）。
- 于是区间 (j, i] 是合法段 ⟺ `pr[i-1] > j` 且 `i - j ≤ k`。

朴素 DP：`dp[i] = min(dp[j]) + 1`，其中 j ∈ [i-k, pr[i]-2]。转移区间是一个**滑动窗口**，用单调队列维护窗口最小值，整体 O(n)：

![单调队列优化划段 DP](/starlight/images/blog/monotonic-queue-dp.svg)

```cpp
// dp[i] = 1 + min{ dp[j] : i-k ≤ j ≤ pr[i]-2 }
// 窗口右端随 i 右移、左端 i-k 也右移 → 单调队列
```

**核心**：看到 `dp[i] = min(dp[j]) + c` 且 j 的范围两端都单调移动，就是单调队列的形状。它和滑动窗口最值是同一个东西。

## 二、组合数系数 + 上下界剪枝（蓝桥杯多校模拟赛一 E）

> **题意**（[蓝桥杯多校模拟赛](https://ac.nowcoder.com/acm/contest/130226) E）：给 n 和 sum，求 1..n 的一个排列 a，使 `Σ C(n-1, i)·a_i = sum`（系数是杨辉三角的一行）。

DFS 全排列是 O(n!)，但剪两刀就快得离谱：**每一层用排序不等式估计当前分支的和的上下界**——剩余数升序配剩余系数降序得下界，升序配升序得上界，若 sum 不在界内立刻回溯：

```cpp
// 每层 O(log) 排序剩余元素，算出 [lo, hi]
// sum < lo || sum > hi → 剪掉整棵子树
```

**核心**："可行性剪枝"不一定要精确，只要一个**便宜又能夹住答案的界**。排序不等式（同序最大、逆序最小）是算这种界最常用的工具。

## 三、两个人走完所有点（苯环杯 H）

> **题意**（["⌬杯"蓝桥杯省赛模拟赛](https://ac.nowcoder.com/acm/contest/130222) H）：数轴上 n 个点，两人都从 0 出发，按编号顺序访问所有点（谁访问都行），最小化两人移动的总距离。

经典的状态设计：`f[i][j]` = 一人刚到 p_i、另一人在 p_j，且前 i 个点都已访问的最小代价。转移两种——要么在 p_i 的人走向 p_{i+1}，要么在 p_j 的人跳过去：

```cpp
f[i+1][j] = min(f[i+1][j], f[i][j] + dist(p_i, p_{i+1}));  // 走的人继续
f[i+1][i] = min(f[i+1][i], f[i][j] + dist(p_j, p_{i+1}));  // 休息的人接棒
```

**核心**："进度 + 两个位置"的双决策者状态是可复用的模板（POJ 2677 Bitonic Tour 同款）。注意 f[i][j] 与 f[j][i] 对称，可以只存 i ≥ j 的一半。

## 四、值域当 DP 数组（牛客周赛 147 D）

> **题意**（[牛客周赛 147](https://ac.nowcoder.com/acm/contest/136224) D）：求数组的最长子序列，使相邻两项的商是质数（即每项 = 前一项 × 某质数）。输出方案。

值域不大时，别用"以 i 结尾"当状态，直接用**值**当状态：`len[x]` = 以数值 x 结尾的最长链。转移枚举 x 的每个质因子 p：`len[x] = max(len[x/p] + 1)`，`pre[x] = x/p` 记前驱，最后从最大处回溯还原路径：

```cpp
for (int x = 2; x <= V; x++)
    for (每个质因子 p of x)
        if (len[x / p] + 1 > len[x]) { len[x] = len[x/p] + 1; pre[x] = x / p; }
```

**核心**：值域 DP 的两个前提——值域可接受、转移只依赖"值的关系"（这里是整除/质因子）。线性筛顺便拿到每个数的最小质因子，枚举质因子就是不断除 spf。

## 五、区间异或变形 → 转增量 + Kadane（洛谷蓝桥国赛模拟 盆栽）

> **题意**（[洛谷蓝桥杯国赛模拟赛 2026](https://www.luogu.com.cn/contest/326698) C 盆栽，已对原题核对）：n 盆花美丽度 a[i]。每次询问给一个魔法值 k：幽香会**选一段区间（也可以不选）**，把区间内每盆的美丽度**按位异或上 k**（区间外不变）。对每个 k 输出浇一次水（或不浇）后总美丽度的最小值和最大值。

"选区间做变换"看起来要枚举 O(n²) 个区间——但变换只影响区间内，而区间外的变化量恒为 0。于是**选区间 = 在增量序列上选子段**（增量 `dif[i] = (a[i] ⊕ k) − a[i]`，⊕ 是异或）：

![转增量后 Kadane 求最优子段](/starlight/images/blog/kadane-delta.svg)

```cpp
// dif[i] = (a[i] ^ k) − a[i]；一趟扫描同时维护最大/最小子段和
long long curx = 0, curn = 0, mx = 0, mn = 0;
for (int i = 1; i <= n; i++) {
    curx = max(0LL, curx + dif[i]); mx = max(mx, curx);
    curn = min(0LL, curn + dif[i]); mn = min(mn, curn);
}
// 最小 = sum + mn，最大 = sum + mx（mn/mx 取 0 对应“不浇水”）
```

**核心**：这是[前缀和的竞赛应用](./2026-08-16-prefix-sum-contest-apps)里"差分视角"的孪生兄弟——**把操作的增量显式化，选区间的问题就塌缩成最大子段和**（Kadane 十行写完）。

## 六、按位或等于和的分段计数（牛客寒假营 1 H）

> **题意**（[牛客寒假营 1](https://ac.nowcoder.com/acm/contest/120561) H Blackboard）：给一个 `+` 和 `|` 组成的表达式串（`|` 优先级更高），问有多少种给运算符序列分段的方式……实质条件：一段内若所有数**两两按位不重叠**，则"或之和 = 求和"。统计使等式成立的分段方案数。

设 `dp[r]` = 前 r 个数合法分段的方案数。关键观察：**"两两无公共位"的段可以双指针维护**——窗口右扩时检查 OR 值是否还等于 XOR（位不重叠的充要条件），失配则左端收缩；转移 `dp[r+1] = pre[r] − pre[l−1]`（前缀和加速区间求和），O(n)。

**核心**："或 = 和 ⟺ 位不重叠"这个等价判定 + 双指针合法段 + 前缀和转移，三个经典组件的干净拼装。

## 小结

| 题 | 暴力 → 正解 |
|---|---|
| 多校二 G 划段 | O(n²) → 单调队列 O(n) |
| 多校一 E 排列 | O(n!) → 上下界剪枝 |
| 苯环杯 H 双人走点 | 状态设计：进度 + 两人位置 |
| 周赛147 D 质数链 | 下标当状态 → 值当状态 |
| 国赛 盆栽 | 枚举区间 → 增量序列上 Kadane |
| 寒假营1 H 分段 | 双指针合法段 + 前缀和 DP |

六道题的共同起点都是一个"显然会超时"的暴力，优化路径各自不同——**先写暴力，再盯着转移的结构看**（区间滑动？界可估？状态冗余？增量可显式化？），几乎是所有 DP/搜索题的通用工作流。
