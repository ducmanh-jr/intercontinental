> **题意**（洛谷 [P3367 【模板】并查集](https://www.luogu.com.cn/problem/P3367)）：n 个元素，两种操作：`M x y` 把 x 和 y 所在集合合并；`Q x y` 问 x 和 y 是否在同一集合。

并查集大概是"性价比"最高的数据结构：**只回答一个问题——两个元素是不是一伙的**，却几乎是所有连通类问题的第一块积木。

思路一句话：每个集合记成一棵树，**"是否同伙" = "根是不是同一个"**。合并两伙 = 把一棵树的根挂到另一棵的根上。

![并查集合并示意](/starlight/images/blog/dsu-merge.svg)

我的模板（带路径压缩 + 按大小合并）：

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
using ll = long long;

// 并查集模板
struct DSU
{
    vector<int> parent, sz;
    // 初始化
    DSU(int n)
    {
        parent.resize(n + 1);
        sz.resize(n + 1, 1);
        for (int i = 1; i <= n; i++)
        {
            parent[i] = i;
        }
    }

    // 查找
    int find(int x)
    {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }

    // 合并
    void unite(int x, int y)
    {
        x = find(x), y = find(y);
        if (x == y)
        {
            return;
        }

        if (sz[x] < sz[y])
        {
            swap(x, y);
        }

        parent[y] = x;
        sz[x] += sz[y];
    }

    // // 获得集合大小
    // int size(int x)
    // {
    //     return sz[find(x)];
    // }

    // 判断是否在同一个集合内
    bool same(int x, int y)
    {
        return find(x) == find(y);
    }
};

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin>>T;

    while (T--)
    {
        int n, m;
        cin>>n>>m;

        DSU dsu(n);

        while (m--)
        {
            int z, x ,y;
            cin>>z>>x>>y;

            if (z == 1)
            {
                dsu.unite(x, y);
            }
            else if (z == 2)
            {
                if (dsu.same(x, y))
                {
                    cout<<'Y'<<endl;
                }
                else
                {
                    cout<<'N'<<endl;
                }
            }
        }
    }

    return 0;
}
```

两个优化各管一件事：

- **路径压缩**（`find` 里的 `parent[x] = find(parent[x])`）：找根的路上顺便把子孙全部直接挂到根上——下次查就是一跳。几乎把树压成"一朵菊花"，均摊复杂度降到反阿克曼级别，可以当成 O(1)；
- **按大小合并**（`sz` 数组）：小树挂大树，保证树高不失控。只用路径压缩其实也够快，但两个一起写就是肌肉记忆。

应用题的代表是 [P1551 亲戚](https://www.luogu.com.cn/problem/P1551)（NOIP 2001 普及组）：若干条"x 和 y 是亲戚"的关系，再问若干对"是不是亲戚"——把每条关系 `unite` 一次，询问就是 `find(x) == find(y)`，同一个模板换了个故事而已。

## 什么时候想到它

- 出现"**连接 / 合并 / 是否相通**"类操作，且不需要具体的连接路径（要路径就是 BFS/DFS 了）；
- Kruskal 最小生成树：边按权排序后逐条"两端点是否已连通"，并查集判重；
- 离线处理的连通性询问、等价类统计（数"还剩几伙" = 数 `find(i) == i` 的根个数）。
