> **题意**（洛谷 [P4779 【模板】单源最短路（标准版）](https://www.luogu.com.cn/problem/P4779)）：n 点 m 边的有向正权图，求从源点 s 到每个点的最短距离。n ≤ 10⁵，m ≤ 2×10⁵。

朴素 Dijkstra 每轮"扫一遍找最近的未定点"，O(n²) 在这题的数据范围下会超时。堆优化版本把"找最近"交给小根堆：

![堆优化 Dijkstra 示意](/starlight/images/blog/dijkstra-heap.svg)

我的提交：

```cpp
#include <bits/stdc++.h>
using namespace std;

#define endl '\n'
using ll = long long;

// 注意不能写 1 << 31 - 1，这样相当于 1 << (31 - 1)
const int INF = (1 << 31) - 1;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin>>T;

    while (T--)
    {
        int n, m, s;
        cin>>n>>m>>s;

        vector<vector<pair<int, int>>> g(n + 1);
        for (int i = 0; i < m; i++)
        {
            int u, v, w;
            cin>>u>>v>>w;

            // 有向边
            g[u].push_back({v, w});
        }

        // Dijkstra板子
        vector<int> dist(n + 1, INF);
        dist[s] = 0;
        priority_queue<pair<int, int>, vector<pair<int, int>>, greater<pair<int, int>>> pq;
        pq.push({0, s});
        while (!pq.empty())
        {
            auto [d, u] = pq.top();
            pq.pop();

            if (d != dist[u])
            {
                continue;
            }

            for (auto [v, w] : g[u])
            {
                if (dist[v] > dist[u] + w)
                {
                    dist[v] = dist[u] + w;
                    pq.push({dist[v], v});
                }
            }
        }

        for (int i = 1; i <= n; i++)
        {
            cout<<dist[i]<<' ';
        }
        cout<<endl;
    }

    return 0;
}
```

三个值得圈出来的点：

1. **惰性删除**。距离更新时旧堆条目不删（优先队列也删不了），出堆时用 `if (d != dist[u]) continue;` 跳过过期条目——`d` 比 `dist[u]` 大，说明这是被更优路线淘汰的旧账。每条边最多进堆一次出堆一次，总复杂度 O(m log m)；
2. **代码里那行注释是我自己的翻车记录**：`1 << 31 - 1` 不加括号时，`-` 优先级高于 `<<`，实际算的是 `1 << 30`。`(1 << 31) - 1` 才是 INT_MAX。写错这个，最短路第二组数据就开始"负距离"了；
3. `pair` 天然按第一维排序，所以堆里存 `(dist, 点号)`，距离放前面。

## 前置条件与常见变体

- Dijkstra 要求**边权非负**——负权图要换 Bellman-Ford / SPFA；
- "多源汇询问"考虑反向图 + 多次 Dijkstra，或者 Floyd（n ≤ 500 时）；
- 输出具体路径：松弛时记 `pre[v] = u`，终点往回走再反转。
