[构造题的两个直觉](./2026-08-16-construct-two-instincts) 讲过"守恒量"和"特殊位置"。这篇补四道比赛题，共同点是**逆向**：不从输入推向输出，而是从"输出长什么样"倒推。

## 一、双排列交叉构造（牛客周赛 144 D）

> **题意**（[牛客周赛 144](https://ac.nowcoder.com/acm/contest/134981) D）：序列 a 中每个数出现不超过 2 次。构造两个 1..n 的排列 b、c，使每个位置满足 b[i] = a[i] **或** c[i] = a[i]。

盯着"每个值出现 ≤ 2 次"这个条件做分类：

- **出现 2 次的值 v**（在 i、j 两处）：b[i] = c[j] = v、c[i] = b[j] = 空——交叉放置，两个排列各"认领"一处；
- **出现 1 次的值**：b、c 同位放置；
- **未出现的值**：恰好填补出现 2 次的值留下的空位——数量守恒（未出现值数 = 出现 2 次值数，因为两排列共 2n 个格子）。

```cpp
// 出现两次 → 交叉认领；出现一次 → 同位；缺失值 → 补空位
// 某值出现 > 2 次直接无解
```

**核心**：构造题先找**数量守恒式**（这里 2n 个格子对应 n 个值各两次），守恒式直接给出构造的骨架。

## 二、方块旋转的逆向重放（蓝桥杯多校模拟赛二 E）

> **题意**（[蓝桥杯多校模拟赛（第二场）](https://ac.nowcoder.com/acm/contest/132303) E）：n×n 网格上依次执行 q 次操作，每次把左上角 (x, y)、边长 len 的子正方形顺/逆时针旋转 90°。最后 d 个询问：某格 (x, y) **最初**在哪里？

正向把每次旋转真做一遍太亏。**所有询问都在操作之后**，于是倒着重放：对每个询问点，从最后一次操作倒序往前，若该点落在某次操作的子方块内，就用**逆向旋转公式**把它映射回去：

```cpp
// 顺时针旋转的逆映射（子方块内相对坐标）：
// (dx, dy) → 顺90: (len-1-dy, dx) → 逆着走就是它的反变换
```

```cpp
for (int op = q; op >= 1; op--)
    if (点在子方块内) 点 = 逆旋转(点);
输出原始下标
```

**核心**："查询原始状态"类问题，只要操作可逆，就倒着重放到查询点上——**移动查询，不移动数据**。复杂度从 O(q·n²) 降到 O(d·q)。

## 三、生成树里的配对邻居（牛客周赛 140 G）

> **题意**（[牛客周赛 140](https://ac.nowcoder.com/acm/contest/132940) G）：n 点 m 边图，点标 A/B/C/D。构造一棵生成树，使每个点在树中至少有一个"配对类型"的邻居（A↔B、C↔D）。

构造前先做**判定**，这是构造题的标准两层结构：

1. **必要性**：A、B 的诱导子图每个连通块必须同时含 A 和 B（否则该块里的点在树里也凑不出配对），C、D 同理；
2. **构造**：先在每个 AB 分量、CD 分量内部连 BFS 树（保证配对边），再跨分量用并查集补齐连通。

**核心**：构造题先问"什么样的输入无解"，无解条件往往就指出构造必须包含的"骨架"。

## 四、正难则反的值域枚举（洛谷入门赛 44 E）

> **题意**（[洛谷入门赛 #44](https://www.luogu.com.cn/contest/311027) E "数学补习"，已对原题核对）：一步变换（按序执行）——① x+y 为奇则 `x -= y mod x`，否则 `y -= x mod y`；② 若 x < c 则 `x += ⌊y/2⌋ + 1`（y 同理，c 是步数计数）；③ c 自增，c < z 就重复。给终态 (x', y') 和 z，问有多少**正的两位数**对 (x, y) 恰好经过该过程变成终态。

从终态逆推变换很绕（变换带取模分支和小数补丁）。但**初态的世界很小**：两位数对一共 90 × 90 = 8100 个——干脆全部枚举，逐个正向模拟 z 步，数终点等于 (x', y') 的个数。

**核心**："正难则反"不一定是逆向推导，也可以是**换一个小的枚举宇宙**。值域 ≤ 10^5 级别时，先看"反过来枚举所有初态模拟一遍"是不是比推导便宜。

## 五、均匀插入：无相邻相同的构造（牛客寒假营 4 F）

> **题意**（[牛客寒假营 4](https://ac.nowcoder.com/acm/contest/120564) F）：用 a 个 0 和 b 个 1 构造一个串，使相邻字符尽量不同（构造类模板：多数方不超过少数方 + 1 时可完全交错）。

模板套路是**插空**：设多数字符有 M 个、少数有 m 个。把 M 个多数排开，形成 M + 1 个空隙，每个空隙塞 0 或 1 个少数字符；按空隙位置均匀分配，剩余的少数字符尽量靠前/靠后放以满足题目对字典序或"最大化相邻不同对"的具体要求。

**核心**："多数 + 1 ≥ 空隙需求"就是可行性判据，均匀分配就是构造——这类题的代码都不长，长的是把分配的余数讨论写干净。

## 六、格雷码（牛客寒假营 4 C）

> **题意**（[牛客寒假营 4](https://ac.nowcoder.com/acm/contest/120564) C）：输出 n 位格雷码序列（相邻两个数恰有一位不同）。

构造公式只要一行：`G(i) = i ^ (i >> 1)`。为什么它满足"相邻恰变一位"？i → i+1 时，低若干位翻转再整体右移一位异或，恰好只让最高变化位翻转一次。**反射法**（前一半加 0、后一半镜像加 1）是同一序列的递归视角。知道这个公式，卡 Duke/格雷码计数题时才有抓手。

**核心**：有些构造题的"构造"其实是"记忆"——公式背后有一分钟就能讲清的证明，值得背下来的还有[勾股数奇偶公式](./2026-08-16-number-theory-roundup)这一族。

## 小结

| 题 | 逆向的形态 |
|---|---|
| 周赛144 D 排列构造 | 从守恒式倒推骨架 |
| 多校二 E 旋转查询 | 移动查询点，不移动数据 |
| 周赛140 G 生成树 | 先判无解，条件即骨架 |
| 入门赛44 E 数学补习 | 枚举小宇宙代替推导 |
| 寒假营4 F 均匀插入 | 多数排开 + 空隙均匀分配 |
| 寒假营4 C 格雷码 | i ^ (i>>1)，构造即记忆 |

"倒过来想"之所以有效，是因为题目总是从输入指向输出，而约束往往藏在输出端。下次构造题卡住时，先写下"答案必须满足什么"，再回头看输入缺什么。
