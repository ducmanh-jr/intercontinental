## 一、约瑟夫环：从模拟到递推

![约瑟夫环递推示意](/starlight/images/blog/josephus.svg)

> **题意**（[约瑟夫环](https://www.nowcoder.com/practice/e417cfe32c74416ca38247f619ddb322)）：n 人围圈从第 k 人报数，报到 m 者出列，从下一位重新报数。求最后的幸存者。

**朴素**：标记数组 + 环形指针 `idx = (idx + 1) % n` 跳过出列者，O(nm)。

**升级**：只关心幸存者的**编号**，设 f(n) 为 n 人（从 0 编号）报到 m 出列后的幸存者。第一轮出列者编号为 (m-1)%n 后，剩下 n-1 人的问题规模缩小，且新起点是 m%n——幸存者在子问题里的编号加上这个偏移就映射回原问题：

```cpp
int josephus(int n, int m) {
    int pos = 0;                    // 1 个人时幸存者是 0
    for (int i = 2; i <= n; i++)
        pos = (pos + m) % i;        // 每加一个人，偏移一个 m
    return pos;                     // 需要再映射回从 k 起报的编号
}
```

O(n) 递推是"删掉模拟过程、只跟踪答案坐标"的典范。

## 二、校门外的树：从标记到差分

> **题意**（[校门外的树](https://www.nowcoder.com/practice/0e8cfc82936048769af45967f3c4ef7e)）：马路长 L，每个整数点一棵树；M 个区间 [a,b] 内的树被砍。求剩下多少棵。

**朴素**：`tree[a..b] = 0` 标记，重复区间自动去重，O(L·M)。

**升级**：区间改点查的集合用**差分**——`d[a]+1、d[b+1]-1`，一遍前缀和还原后数非零点，与 L 无关的 O(M + L) 且能推广到动态询问（参见[前缀和的竞赛应用](./2026-08-16-prefix-sum-contest-apps)）。

## 三、扫雷：方向数组与"外圈护栏"

> **题意**（[扫雷](https://www.nowcoder.com/practice/d5f277427d9a4cd3ae60ea6c276dddfd)）：给雷区图（`*` 雷 `.` 空），输出每格周围 8 邻域的雷数。

**朴素**：每格 8 个 if 分别判边界——能过，但又长又容易漏。

**升级**两个技巧打包：

```cpp
int dx[] = {-1,-1,-1, 0, 0, 1, 1, 1};
int dy[] = {-1, 0, 1,-1, 1,-1, 0, 1};
// 读入时矩阵外围补一圈 '.'，循环内就永远不用判边界
```

**外圈补哨兵**和**方向数组**是网格题的通用零件，BFS/DFS 搜图同款（见[BFS 刷题记](./2026-08-16-bfs-on-graphs)）。

## 四、杨辉三角：递推即组合数

> **题意**（[杨辉三角](https://www.nowcoder.com/practice/8c6984f3dc664ef0a305c24e1473729e)）：输出杨辉三角前 n 行。

`a[i][j] = a[i-1][j] + a[i-1][j-1]`，边界为 1。值得多看一眼的是它**就是** C(i-1, j-1) 的递推——加法公式。两个直接收益：

- 需要组合数但模数不友好（不能逆元）时，杨辉三角 O(n²) 预处理是保底方案；
- "每个格子由上方/左上方递推"的形状，是路径计数 DP 的直系祖先（[走方格](https://www.nowcoder.com/practice/12da4185c0bb45918cfdc3072e544069)那题就是它换皮）。

## 五、数字串的第 n 位：从暴力拼接到按位分块

> **题意**（[无限长正整数排列字符串](https://www.nowcoder.com/practice/82c92d2321bb4220a3006d52a95a8bdd)）：s = "123456789101112…"，求第 n 位数字。

**朴素**：`to_string` 一个个拼，拼够 n 位为止——n ≤ 1e6 内能过，再大就炸。


LeetCode 400 同款。"**先分层再定位**"是所有数位统计题的骨架（[记数问题](https://www.nowcoder.com/practice/28b2d9f3bf2c48de94a1297ed90e1732)——数 1..n 里数字 x 出现次数——可以从暴力逐位查升级到按位 O(log n) 统计，同一思想）。

## 小结

| 题 | 朴素 → 升级 |
|---|---|
| 约瑟夫环 | 标记模拟 O(nm) → 递推公式 O(n) |
| 校门外的树 | 区间标记 → 差分 |
| 扫雷 | 8 个 if → 方向数组 + 外圈护栏 |
| 杨辉三角 | 递推表 → 组合数保底方案 |
| 数字串第 n 位 | 暴力拼接 → 按位分块定位 |
