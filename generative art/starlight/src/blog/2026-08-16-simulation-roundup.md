模拟题常被当成"送分"，但比赛里的模拟题会藏三个考点：**遍历顺序怎么组织**、**数据范围暗示的暴力形状**、**过程太长时要找周期**。四道题各占一个。

## 一、蛇形吃蛋糕（洛谷入门赛 44 F）

> **题意**（[洛谷入门赛 #44](https://www.luogu.com.cn/contest/311027) F "草莓蛋糕"，已对原题核对）：n×m 蛋糕网格（1 = 有草莓），从 (1,1) 起按蛇形顺序吃。每轮先吃 d 个位置；若蛋糕没吃完，看**下一个要吃的位置**：恰好有草莓就再吃 d 个，否则停止（中途吃完整块蛋糕也直接停）。问最终吃掉多少颗草莓。

蛇形 + 分天 + 提前终止，三个逻辑搅在一起最容易写错。解法是**先解耦再消费**：把蛇形顺序的所有坐标一次性预生成到数组 idx 里，之后"天"的逻辑只是在序列上按块切分：

![蛇形遍历预生成序列](/starlight/images/blog/snake-order.svg)

```cpp
// 1) 预生成蛇形序列 idx[0..n*m)
// 2) 按天消费：每天取 min(d, 剩余) 块，统计草莓
// 3) 停止条件独立成一个小函数，别揉进遍历里
```

**核心**：模拟题的工程问题是耦合。把"遍历逻辑"（蛇形）与"业务逻辑"（分天、停止）拆成两段，各自的边界条件才检查得清楚。

## 二、恰好 d 种颜色的最大子矩阵（洛谷入门赛 44 H）

> **题意**（同场 H "弹珠方阵"）：n×m 网格每格一种颜色（颜色数 ≤ 400），求**恰好含 d 种颜色**的子矩阵的最大面积。

这题题面平平无奇，数据范围才是题眼：**n·m ≤ 400（而不是 n, m ≤ 400）**。子矩阵对数约 `(n·m)²/4`，每个再 O(n·m) 扫颜色——总量约 `(400)³/4 ≈ 1.6×10⁷`，可过：

```cpp
// 四重循环枚举子矩阵两角 + 内部桶计数颜色种数
// O((n·m)³) 量级在 n·m ≤ 400 时恰好安全
```

**核心**：读题先看范围的"形状"。`n·m ≤ X` 说的就是"我允许你做一个关于总面积三次方的算法"。同理 `Σn ≤ X` 允许多测里每个 n²、`q 很小`允许每次 log²。**数据范围是出题人留给你的复杂度合同**。

## 三、队列对决的周期（苯环杯 E）

> **题意**（["⌬杯"蓝桥杯省赛模拟赛](https://ac.nowcoder.com/acm/contest/130222) E）：n 人排队，每轮队首两人对决，胜者回队首、败者排队尾，进行 k 轮，输出最终队列。k 可达 1e18。

直接模拟一轮 O(1)，但轮数上天。观察：**最大值第一次到达队首后，它就再也不离开**，剩下 n-1 个人的相对顺序进入周期 (n-1)/(n-1) 的循环：

```cpp
// 1) 暴力模拟直到最大值到队首（至多 n 轮）
// 2) 剩余轮数 rem 对 (n-1) 取模，再模拟 rem % (n-1) 轮
```

**核心**：大步数模拟题先找"**不变量出现时刻**"（这里是最强者就位），从那一刻起过程必然进入周期，取模跳过。

## 四、可爱日期（洛谷蓝桥省赛模拟 A）

> **题意**（[洛谷蓝桥杯省赛模拟赛 2026](https://www.luogu.com.cn/contest/314564) A，填空）：统计 2239-09-09 至 9876-01-01 之间"可爱日期"的个数：日期的年月日十进制写法中，每个数字出现的次数完全相同。

年份上限 9876，总共约 280 万天——**直接枚举每一天**，数位桶统计后检查非零频次一致。要点全在写法稳：闰年函数、月天数表、进位逻辑分段写清楚。蓝桥填空题里，日期枚举是和"纯手玩"并列的两大保底流派，值得练成肌肉记忆。

## 小结

| 题 | 考点 |
|---|---|
| 入门赛44 F 蛇形蛋糕 | 预生成序列，遍历与业务解耦 |
| 入门赛44 H 弹珠方阵 | 读数据范围的"形状"定暴力 |
| 苯环杯 E 队列对决 | 找不变量出现时刻 + 周期取模 |
| 省模拟 A 可爱日期 | 日期枚举模板 |

模拟题不丢分靠的不是手感，是**组织方式**：预处理、分模块、看范围、找周期——四个习惯让最"朴素"的题型也稳稳当当。
