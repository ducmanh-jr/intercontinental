**倍增**回答的是同一类问题："沿某个函数 f 跳 k 步之后在哪？" 当 k 高达 10^18，逐步跳不可行——预处理 `fa[j][i] = f^(2^j)(i)`，把 k 的二进制位逐位消费：

![倍增跳跃](/starlight/images/blog/doubling-jump.svg)

```cpp
for (int j = 1; j < LOG; j++)
    for (int i = 1; i <= n; i++)
        fa[j][i] = fa[j - 1][fa[j - 1][i]];
```

**分治**则管另一类：大问题劈两半，跨两半的贡献在"合并瞬间"算清。

## 一、Frog：第 k 近跳 m 步（洛谷 P3509）

> **题意**（[POI2010 ZAB-Frog](https://www.luogu.com.cn/problem/P3509)）：数轴上 n 块石头（坐标升序），第 i 只青蛙每次跳到**距离第 k 近**的石头（保证唯一）；跳 m 次后各在哪。

先建 f：排序后对每个 i，第 k 近的石头必落在 `[i−k, i+k]` 窗口内，双指针 O(n) 找出；然后对 f 做标准倍增，m 按二进制消费。m ≤ 10^18 也只是 60 层表。

## 二、喷泉：溢流链上的容量和（洛谷 P7167）

> **题意**（[eJOI2020 喷泉](https://www.luogu.com.cn/problem/P7167)）：n 个圆盘各有直径 d、容量 c；向 r 号圆盘倒 v 单位水，装满后溢向**右侧第一个直径更大**的圆盘；问水最终留在哪个圆盘。

两步组合拳：**单调栈** O(n) 建出溢流链 nxt[i]（右侧第一个更大直径——就是"下一个更大元素"），**倍增**时多维护一列 `sum[j][i]` = 沿途 2^j 个圆盘容量和。查询从高位往低位跳：能装下就跳，装不下就缩小——本质是"链上第一个前缀和 ≥ v 的位置"。

**核心**：倍增表里可以**背包任意额外信息**（容量和、边权最值、路径计数……），跳到哪信息就跟到哪。

## 三、火柴排队：相邻交换 = 逆序对（洛谷 P1966）

> **题意**（[NOIP2013 火柴排队](https://www.luogu.com.cn/problem/P1966)）：两列火柴各有高度，可任意交换**相邻**两根，最小化 Σ(a_i − b_i)²，输出最少交换次数 mod 998244353。

排序不等式说 a、b **同序**时距离和最小（平方同样成立）。于是把 a 的名次映射到 b 的名次，得到一个排列，最少相邻交换次数 = **逆序对数**——每次交换至多消一个逆序，而冒泡排序恰好能一个一个消。逆序对用归并分治数：合并两个有序段时，右段元素出队时左段剩余个数即跨段逆序数。

```cpp
ll merge_count(int l, int r) {           // [l, r)
    if (r - l <= 1) return 0;
    int m = (l + r) / 2;
    ll cnt = merge_count(l, m) + merge_count(m, r);
    // 归并合并：右段出队时 cnt += 左段剩余数量
    return cnt;
}
```

**核心**：交换类下界问题先找"目标形态"（同序/同集），最少相邻交换 = 排列的逆序对，这是组合恒等式不是巧合。

## 四、把前缀和搬上树（洛谷 P4427）

> **题意**（[P4427](https://www.luogu.com.cn/problem/P4427)，形式化）：n 个点的树以 1 为根，q 次询问 (u, v, k)：路径 u→v 上每个点 w 的 dep(w)^k 之和（k ≤ 50）。

一维前缀和的树上版：`f[v][k] = f[parent][k] + dep(v)^k` 沿 BFS 一遍算出"根到 v"的和；路径和用它拆——

```text
Σ path(u,v) = f[u] + f[v] − f[lca] − f[parent(lca)]
```

lca 用**倍增**求（跳 2^j 层的表）。每个点存 50 个幂次和（快速幂或沿 BFS 增量乘），查询 O(log n)。

**核心**：前缀和的加减拆分在树上依然成立——倍增表顺带解决了"LCA 从哪拆"的问题；"树链 = 两条根链拼起来"是所有树链统计的第一步。

## 小结

| 题 | 结构 | 倍增/分治带的信息 |
|---|---|---|
| P3509 Frog | 第 k 近邻链 | 到达点 |
| P7167 喷泉 | 单调栈溢流链 | 到达点 + 容量和 |
| P1966 火柴排队 | 名次排列 | 归并数逆序对 |
| P4427 树上前缀和 | 根链和 + LCA | 跳 2^j 层的祖先表 |
