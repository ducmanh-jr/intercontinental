欢迎来到我的博客。

很长一段时间里，我的学习产物只有两类：OJ 上的提交记录，和硬盘里的项目代码。前者没有上下文，后者没有读者。写博客是给这些积累补上"为什么"和"怎么想"——所以这里会记录三类内容：

- **算法复盘**：竞赛与题目中的思路总结。例如 [2048 策略进化竞技场](./2026-08-10-2048-ai-strategies) 里 14 种 AI 策略的进化过程——从随机乱按到 74% 胜率，中间每一步踩过的坑；
- **项目笔记**：从 Java Swing 游戏到 PySide6 桌面应用，把"做完"之后才想明白的事情写下来；
- **Web 与性能**：这个网站本身就是一个持续更新的例子——粒子系统怎么控制预算、SPA 在 GitHub Pages 上怎么不 404，都会变成文章。

## 关于这个网站

它是 Vue 3 + TypeScript + Vite + Three.js + GSAP 搭的，部署在 GitHub Pages。开发前先写了设计文档，再拆成 21 个任务逐个实现、逐个审查，全程用截图加视觉模型做验收。驱动这套流程的是我的 AI Agent 工作流：主力是 deepseek-v4-pro 这类 LLM 搭配 Claude Code 这样的 Agent——模型负责推理与生成，Agent 提供终端、文件系统与浏览器的操作能力；最近则在用 deepseek harness + deepseek-v4-flash 的轻量组合跑「规划-执行-审查」的自动循环。这个过程本身就值得一篇文章——见《[从零搭建 Vue3 + Three.js 个人网站：性能优化实录](./2026-08-14-vue3-portfolio-performance)》。

## 我的学习路线

回头看，我的学习轨迹大概是这样的：

- **算法与竞赛**：从洛谷刷题到蓝桥杯，用 C++ 和 Python 打磨数据结构与复杂度的直觉——这是后面所有项目的地基；
- **工程落地**：把想法做成能跑的东西：Java Swing 游戏（[Galaxy Defender](https://github.com/xrk-hhh/Galaxy-Defender)）、PySide6 桌面应用（[Art Style Transfer](https://github.com/xrk-hhh/Art-Style-Transfer)）；
- **AI 与系统**：开始关心"程序怎么变聪明、怎么跑得快"——[2048 Strategy Arena](https://github.com/xrk-hhh/2048-Strategy-Arena) 的 14 种 AI 策略、位板引擎的性能压榨，以及现在这个网站的 GPU 粒子与性能预算。

下一个方向是更深入地探索 AI 应用与前端工程化，并把这些过程继续记录在这里。

写博客对我而言是一种"输出倒逼输入"：把一个模糊的 idea 讲清楚，往往比写完代码更难。如果这些记录对你有用，欢迎通过邮箱联系我交流。
