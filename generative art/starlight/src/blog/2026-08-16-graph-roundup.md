图论的入门三件套（[BFS](./2026-08-16-bfs-on-graphs)、[Dijkstra](./2026-08-16-dijkstra)、[并查集](./2026-08-16-dsu)）我都单独写过。这篇收四道比赛题，看这些模板在真题里怎么"改装"。

## 一、连接两个不同特殊点的最短路（蓝桥杯多校模拟赛二 H）

> **题意**（[蓝桥杯多校模拟赛（第二场）](https://ac.nowcoder.com/acm/contest/132303) H）：n 点 m 边带权无向图，其中 k 个是特殊点。求一条最短路，两端是**两个不同**的特殊点。

把 k 个特殊点全塞进优先队列一起跑 Dijkstra（多源），同时给每个点记录**最近的源是谁**（src 数组）。答案在**松弛失败**的时刻收集：处理边 (u, v) 时若 `dist[u] + w < dist[v]` 不成立且 `src[u] != src[v]`，则 `dist[u] + w + dist[v]` 是一条"连接两个不同源"的候选路径：

![多源 Dijkstra 势力范围](/starlight/images/blog/multisource-dijkstra.svg)

```cpp
if (du + w < dv) { dist[v] = du + w; src[v] = src[u]; push(v); }
else if (src[u] != src[v]) ans = min(ans, du + w + dv);
```

**为什么是松弛失败时统计**：松弛成功说明 v 还在"源 src[u] 的势力范围"内，路径还没闭合；失败的那条边恰好是两个势力范围的交界。这个技巧可推广到一大类"多源汇合 / 最近关键点对"问题。

## 二、前缀点集都在同一条链上（苯环杯 G）

> **题意**（["⌬杯"蓝桥杯省赛模拟赛](https://ac.nowcoder.com/acm/contest/130222) G）：给一棵树和序列 p，求最大的 k，使 p 的前 k 个点都落在树的**某一条简单路径**上。

维护"当前链的两端 a、b"，逐个加入点 x（用倍增 LCA 判位置）：

- x 在 a→b 路径上：无事发生；
- b 在 a→x 路径上：b = x（链往 x 方向延伸）；
- a 在 b→x 路径上：a = x；
- 都不满足：x 无论如何都进不来，停止。

这个"**增量维护链端点**"和树上直径的两次 BFS 是同一族思想：一条链由它的两个端点唯一确定。官方解法是二分 k + DFS 判定，两种解法复杂度同阶，但增量法更好写。

## 三、k 个检查点最少几条路径（洛谷蓝桥省赛模拟 H）

> **题意**（[洛谷蓝桥杯省赛模拟赛 2026](https://www.luogu.com.cn/contest/314564) H）：n 点树上选 k（k ≤ 4）个点作检查点，覆盖它们最少需要几条简单路径（若 k 个点共链则 1 条，否则 2 条）。对所有 C(n, k) 个集合求路径条数之和，模 998244353。

先盯结论：**树上 k 个点的最小路径覆盖只可能是 1 或 2**（k ≥ 2 时，一条链放不下就两条拼）。于是：

```cpp
答案 = 2·C(n,k) − good    // good = “k 点共链”的集合数
```

剩下的就是数 good：树形 DP，`f[u][x]` 维护"u 的子树里，选 x 个点、全部落在一条过 u 向下的单臂链上"的方案数；在每个点 u 处，把两个不同儿子方向的单臂拼成一条**过 u 的完整路径**时累入 good。k ≤ 4 保证 x 的枚举量是常数。

**核心**："答案 = 常数 × 总数 − 特殊形态数"的转化，把构造题变成计数题。

## 四、交换位置排序（牛客周赛 140 D/E）

> **题意**（[牛客周赛 140](https://ac.nowcoder.com/acm/contest/132940) D/E）：每次可以交换下标差**恰好为 x 或 y** 的两个位置。问能否把排列 p 变成 1..n 递增（E 与 D 题意相同、数据加大）。

只看下标：位置 i 能与 i+x、i+y 互换，等价于这些下标在一个连通块里可以**任意重排**（交换连通块内任意两个元素的技巧：用类似冒泡的传递）。所以判定就是——

```cpp
for (int i = 1; i + x <= n; i++) union(i, i + x);
for (int i = 1; i + y <= n; i++) union(i, i + y);
// 能排序 ⟺ 每个 i 与 p[i] 同一连通块
```

easy 和 hard 同解这件事本身就有教育意义：**看清"操作真正改变的是位置集合的连通性"，数据范围再大也不怕**。

## 五、带解锁时间的扩散（牛客寒假营 6 D）

> **题意**（[牛客寒假营 6](https://ac.nowcoder.com/acm/contest/120566) D）：网格里有 a 个扩散源，但某些格子要到时刻 t ≥ t[格子] 才"解锁"可通行。求所有格子全部被占据的时刻。

多源 Dijkstra 的经典变体：边权仍是 1，但到达一个格子的时间还要**等它解锁**——松弛时把到达时间改成 `nd = max(d + 1, t[nx][ny])`，其余流程不变，答案是最终的最大 dist。为什么 Dijkstra 依然对？因为 `max(d+1, t)` 关于 d 单调不减，"先到的不会更晚"的贪心性质保住了。

**核心**：判定 Dijkstra 能不能用的唯一问题是"边权扩展后 `dist` 是否还随路径单调"——带等待时间、带冷却时间都是这一款。

## 六、高度阈值下的连通块计数（牛客寒假营 6 E）

> **题意**（[牛客寒假营 6](https://ac.nowcoder.com/acm/contest/120566) E）：节点带高度 h 的图。每次询问给阈值 H：只保留 h > H 的"激活点"，问此时大小 ≥ d 的连通块有几个。

离线 + 并查集是绝配：询问按 H **降序**、节点按高度**降序**，双指针逐步"点亮"节点——每点亮一个就 `union` 它的已点亮邻居，并增量维护"大小 ≥ d 的连通块计数"（合并两个 <d 的块可能恰好跨过 d，要加减仔细）。每个询问在它对应时刻读一次当前计数，O((n+q) α)。

**核心**："在线单调加点"就离线排序——把询问的时间轴变成节点的插入轴，[并查集](./2026-08-16-dsu)从静态判定器变成增量计数器。

## 小结

| 题 | 模板 | 改装点 |
|---|---|---|
| 多校二 H | 多源 Dijkstra | src 标记 + 松弛失败时统计 |
| 苯环杯 G | 倍增 LCA | 增量维护链两端 |
| 省模拟 H | 树形 DP | 结论转化：2·C(n,k) − 共链数 |
| 周赛140 D/E | 并查集 | 置换连通性判定 |
| 寒假营6 D | Dijkstra | nd = max(d+1, t) 的等待时间 |
| 寒假营6 E | 离线并查集 | 降序双指针 + 连通块大小计数 |

模板题到真题之间隔的就是这层"改装"：多记一个**不变量**（势力范围、链端点、连通块），题目就从一个暴力模拟变成模板的直接应用。
