## 一、因子幂和（牛客周赛 143 C）

> **题意**（[牛客周赛 143](https://ac.nowcoder.com/acm/contest/134529) C）：多组数据，每次给 x、y，求 x·y 的所有因子 d 的 `d^d` 之和，模 1e9+7。

x·y 可达 1e12，因子不能试除到根号（多组数据会 TLE）。正解两步：

1. **质因数分解**：分别分解 x 和 y（各自 ≤ 1e6 的试除即可），合并指数得到 xy 的标准分解。
2. **DFS 枚举因子**：按每个质因子的指数做笛卡尔积，逐层乘出所有因子，对每个 d 累加快速幂 `ksm(d, d)`。

```cpp
// 分解形如 p1^e1 · p2^e2 · ...，DFS 每层枚举当前质因子的次数
void dfs(int i, long long d) {
    if (i == k) { ans = (ans + qpow(d % MOD, d)) % MOD; return; }
    long long cur = 1;
    for (int j = 0; j <= e[i]; j++) { dfs(i + 1, d * cur); cur *= p[i]; }
}
```

**核心**：因子个数在 1e12 级别最多约 6700 个，"标准分解 + 笛卡尔积枚举"远优于逐个试除；`d^d` 这种自指幂交给快速幂。

## 二、构造直角三角形（牛客周赛 140 F）

> **题意**（[牛客周赛 140](https://ac.nowcoder.com/acm/contest/132940) F）：多组询问给整数 x，构造一条直角边为 x、三边都是整数的直角三角形；无解报告之。

这是**已知公式就能秒、不知道只能干瞪眼**的题。x ≤ 2 无解（2 的勾股搭档不存在），其余套奇偶两条公式：

```cpp
if (x % 2 == 1)  // 奇数：x² = ((x²-1)/2) + ((x²+1)/2)，1 的平方差
    b = (x*x - 1) / 2, c = (x*x + 1) / 2;
else             // 偶数：令 x = 2m，用 (2m)² + (m²-1)² = (m²+1)²
    b = (x/2)*(x/2) - 1, c = (x/2)*(x/2) + 1;
```

以 x = 5 为例，得到直角边 5、12、斜边 13：

![勾股数的平方差构造](/starlight/images/blog/pythagorean-construction.svg)

两条公式都来自平方差 `c² - b² = x²` 的因式分解：(c-b)(c+b) = x²，奇数时取 c-b=1、c+b=x²；偶数时 x=2m 配 c-b=2。**记住推导而非结论**：平方差分解是所有勾股数公式的源头。

## 三、合成西瓜的翻倍规律（洛谷蓝桥省赛模拟 D）

> **题意**（[洛谷蓝桥杯省赛模拟赛 2026](https://www.luogu.com.cn/contest/314564) D）：两个低级西瓜可以合成一个高一级的西瓜；等级 ≤ y 的西瓜可以直接获得 1 个。问合成一个等级 x 的西瓜最少需要多少个基础西瓜，答案模 998244353。

手玩前几级找规律：x ≤ y 时答案是 1；x > y 后，凑出第一个 (y+1) 级要 (y+1) 个基础瓜，之后每升一级数量**翻倍**（两两合并）：

```cpp
// f(x) = 1                     (x ≤ y)
// f(x) = (y+1) · 2^(x-y-1)     (x > y)
```

x 可达 1e18，幂次用快速幂取模。**核心**：合成/合并类问题的递推往往一段常数、一段等比，先把前 6~8 项列出来看"从哪一项开始倍增"，比硬推递推式快得多。

## 四、不定方程最小化 max（牛客寒假营 4 D）

> **题意**（[牛客寒假营 4](https://ac.nowcoder.com/acm/contest/120564) D）：求 `a·c1 + b·c2 = x` 的非负整数解，使 max(c1, c2) 最小；无解输出 No。

裸 exgcd 全流程展示：扩欧求出特解后，通解是 `c1 = c1₀ + k·b/g`、`c2 = c2₀ − k·a/g`（g = gcd）。k 的可行区间由 c1, c2 ≥ 0 夹出来，最优点在 `c1 ≈ c2` 附近——直接在 `(c1₀ − c2₀)/(a/g + b/g)` 邻域取几个候选 k 比较即可。a·c1 可能爆 long long，上 `__int128`。

**核心**：exgcd 题的通用骨架 = 特解 → 通解 → 可行区间 → 目标函数在区间上取最优。四个步骤写熟练，这类题就是填空。

## 五、扩域快速幂解 Pell 型填空（洛谷蓝桥国赛模拟 谜题）

> **题意**（[洛谷蓝桥杯国赛模拟赛 2026](https://www.luogu.com.cn/contest/326698) B 谜题，填空，已对原题核对）：称 n 为"必胜棋子数"，若 **2n+1 和 3n+9 都是完全平方数**。求第 114514 小的必胜棋子数，mod 223999（质数）。

设 2n+1 = a²、3n+9 = b²，消去 n 得 `2b² − 3a² = 15`——Pell 型方程。两边乘 2 配方成 `(2b)² − 6a² = 30`，它的解由 x²−6y²=1 的**基本解 (5, 2)** 的幂生成：`(5 + 2√6)ⁿ = aₙ + bₙ√6`。问题变成在 **Q(√6) 扩域**上做快速幂——把 `a + b√6` 当二分量向量，乘法是 `(a₁a₂ + 6b₁b₂) + (a₁b₂ + a₂b₁)√6`，完全平行于复数乘法。幂次 log 步算完，取有理分量还原 n，除法用费马小定理求逆元。

**核心**："矩阵/扩域快速幂"的本质是**任何结合代数上的幂都能二分**。复数幂算斐波那契、扩域幂解 Pell、[矩阵幂加速递推](./2026-08-16-matrix-power-acceleration)是同一招的三张皮。

## 六、找一对不互质的数（牛客寒假营 3 B）

> **题意**（[牛客寒假营 3](https://ac.nowcoder.com/acm/contest/120563) B）：数组里找一对共享某个质因数的数并输出；都两两互质则输出 −1。

埃氏筛出质数表后，对每个 a[i] 试除分解（值域内均摊很快），用哈希表记**每个质因数首次出现的下标**——分解途中撞见已有记录的质因数立即输出配对。值域大时换成"最小质因子筛 + 一次除链"分解更快。

**核心**："不互质 ⟺ 共享质因子"的翻译，加上"质因子当哈希键"的登记手法，数论题里出场率极高。
