线段树的全部秘密一句话：**每个节点负责一段连续区间，询问拆成 O(log n) 个整节点**。难点只有两个——lazy 标记怎么下传，节点信息怎么合并。

![线段树：节点管区间](/starlight/images/blog/segment-tree.svg)

## 一、模板：区间加与区间乘（洛谷 P3372 / P3373）

> **题意**（[线段树 1](https://www.luogu.com.cn/problem/P3372) / [线段树 2](https://www.luogu.com.cn/problem/P3373)）：维护序列，支持区间加、区间乘（模板 2），询问区间和。

单标记（加）时 lazy 直接累加；**加乘双标记**必须规定顺序：乘法先于加法，节点值统一维护成 `val = Σa·mul + add`。下传时先传乘再传加：

```cpp
void push_down(int p) {
    apply(ls, mul[p], add[p]); apply(rs, mul[p], add[p]);
    mul[p] = 1; add[p] = 0;
}
// apply(p, m, a)：sum = sum*m + a*len；mul = mul*m；add = add*m + a
```

**核心**：双标记的次序就是代数结构 `val·m + a` 的复合顺序——把它写在纸上，下传代码照抄不会错。

## 二、忠诚：区间最小值（洛谷 P1816）

> **题意**（[忠诚](https://www.luogu.com.cn/problem/P1816)）：动态询问区间最小值，全部输出在一行。

把"合并运算"从 `+` 换成 `min`，其余一字不改。这是线段树的第一课：**可结合、可重复贡献的信息都能上树**（和、最值、gcd、按位或……）。

## 三、小白逛公园：最大子段和（洛谷 P4513）

> **题意**（[小白逛公园](https://www.luogu.com.cn/problem/P4513)）：单点修改，询问区间的最大子段和（至少选一个数）。

单点信息不够合并，节点必须存**四元组**：区间和 `sum`、前缀最大 `pre`、后缀最大 `suf`、整体最大 `mx`。合并时左后缀拼右前缀：

```cpp
node merge(node A, node B) {
    return { A.sum + B.sum,
             max(A.pre, A.sum + B.pre),
             max(B.suf, B.suf + A.suf),
             max({A.mx, B.mx, A.suf + B.pre}) };
}
```

**核心**："合并需要什么就多存什么"——最大子段和的四元组是所有区间信息设计题的模板。

## 四、花神游历各国：开方势能（洛谷 P4145）

> **题意**（[花神游历各国](https://www.luogu.com.cn/problem/P4145)）：区间开平方（下取整），区间求和，值域 ≤ 10^12。

暴力开方会 TLE，但 10^12 开方 6 次就到 1，**到 1 或 0 后再开不变**。节点记区间最大值，若 ≤ 1 直接返回，否则下潜到叶子单点改。总复杂度均摊 O((n + q) log n · log V)——这就是**势能线段树**：操作让数据"越来越平凡"，平凡就剪枝。

## 五、开关：01 翻转（洛谷 P3870）

> **题意**（[TJOI2009 开关](https://www.luogu.com.cn/problem/P3870)）：01 串，区间取反，询问区间 1 的个数。

lazy 是一个布尔：下传时 `sum = len − sum, tag ^= 1`。注意取反两次等于没翻，lazy 用**异或**而不是加法累积——这是"标记运算跟着信息运算走"的又一次重复：信息世界的 `1−x` 对应标记世界的 `^`。

## 六、逆序对：分治视角（洛谷 P1908）

> **题意**（[逆序对](https://www.luogu.com.cn/problem/P1908)）：求数列中 i < j 且 a_i > a_j 的对数。

归并排序的副产物：合并两个有序段时，右段元素提前出队多少次，就是它跨出的逆序对数。树状数组也能做（离散化 + 单点加 + 前缀和），但归并的**"左右各自有序，跨段贡献在合并瞬间算清"**是分治题的通用手感。
