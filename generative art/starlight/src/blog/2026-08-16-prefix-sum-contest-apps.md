[前缀和：O(1) 查询区间和](./2026-08-16-prefix-sum) 讲的是最基础的形态。打了几场比赛后我发现：**前缀和真正的考点不是"求和"，而是"把询问拆成两个前缀状态的差"这个思想**。这篇收集三道真题，都是这个思想的变形。

## 一、回文子序列计数（牛客周赛 141 F）

> **题意**（[牛客周赛 141](https://ac.nowcoder.com/acm/contest/133523) F）：给字符串 s（仅小写字母）和 q 次询问，每次给 `l r x`，问 s[l..r] 里长度**恰好为 x** 的回文**子序列**有多少个（x ≤ 3）。

子序列 + 区间询问 + 多测，直接枚举必炸。按 x 分情况，每一档都是前缀和的变形：

- **x = 1**：答案就是区间长度 `r - l + 1`。
- **x = 2**：两个字符相同即可。对每个字符 c 维护出现次数前缀 `cnt[c][i]`，答案为 `Σ_c C(cnt[c][r] - cnt[c][l-1], 2)`。
- **x = 3**：回文子序列形如 `s_i = s_k`（i < k），中间任选一个点。枚举右端 k，设 P 为 [l, k-2] 中与 s_k 相同字符的位置集合，贡献是 `Σ_{i∈P} (k - i - 1) = k·|P| - ΣP - |P|`。其中 `|P|` 用计数前缀、`ΣP`（**位置下标的前缀和**）再用一层前缀数组维护——这就是"二阶前缀和"。

```cpp
// x = 3 的核心：位置前缀和 cnt[c][i] + 下标前缀和 sum[c][i]
// 单次询问 O(26·n)，把"数对 + 距离"型询问拆成前缀状态之差
ans += k * (cnt - 1) - (sumK - sumL) - (cnt - 1);
```

**核心**：凡是"统计满足某种对称条件的数对，且贡献与距离有关"的询问，都可以往 `个数前缀 × 下标前缀` 上想。

## 二、可延伸区间的最大重叠（牛客周赛 143 D）

> **题意**（[牛客周赛 143](https://ac.nowcoder.com/acm/contest/134529) D）：给 n 个区间 [l, r]，每个区间可以向左延长**至多** k（变成 [l-k, r]）。要求所有区间同时取一个延长量，使某个点被覆盖的层数最大。

乍看要枚举"延长多少"，其实不用：既然所有区间统一延长 k，等价于直接把每个区间的左端点挪到 `l - k`。问题退化成**静态的最大重叠层数**——扫描线模板题：

![扫描线最大重叠示意](/starlight/images/blog/sweep-line.svg)

```cpp
// 事件化：进入 +1，离开 -1，扫一遍取前缀和最大值
events.push_back({l - k, +1});
events.push_back({r + 1, -1});
sort(events);
// max{running sum} 即答案
```

**核心**：扫描线本质是"差分 + 排序后求前缀和"。区间类问题先想能不能把"操作"变成±1 事件，剩下的就是排序。

## 三、环上差分维护"权值"（牛客周赛 147 C）

> **题意**（[牛客周赛 147](https://ac.nowcoder.com/acm/contest/136224) C 魔物76，已对原题核对）：定义数组的权值为 `Σ ((b[i+1] − b[i]) mod 5 + 5) mod 5`。给数组 a 和 q 次操作，每次把区间 [l, r] 整体 +1，**每次操作后**输出当前数组的权值（操作累积不独立，n, q ≤ 2×10⁵）。

每次操作后都输出，若暴力每次 O(n) 重算就是 O(nq)。观察权值只依赖**相邻差分数组** d[i] = (a[i+1] - a[i]) mod 5：区间 [l, r] 整体 +1 时，d 只有**两处**会变——d[l-1] 在环上 +1、d[r] 在环上 -1。于是把"修改区间"降成"修改两个点"，权值和跟着 O(1) 增删：

```cpp
// 区间 [l, r] +1  ⇒  差分环上只动两个格子
sum -= d[l-1]; d[l-1] = (d[l-1] + 1) % 5; sum += d[l-1];
sum -= d[r];   d[r]   = (d[r]   + 4) % 5; sum += d[r];   // -1 ≡ +4 (mod 5)
```

**核心**：差分的价值不只是"区间修改 + 单点查询"，而是**任何只依赖相邻关系的目标函数，都可以把区间操作降维成端点操作**。

## 四、子段和模 p 的最大值（牛客寒假营 5 E）

> **题意**（[牛客寒假营 5](https://ac.nowcoder.com/acm/contest/120565) E）：给数组 a 和质数 p，求**一段连续子数组**的和模 p 的最大值，并输出该子段。

`区间和 ≡ pre[r] − pre[l−1] (mod p)`，于是对每个右端点 r，要在历史余数里找让差**最大**的那个 pre[l−1]：要么找 `≤ pre[r]` 的最大历史余数（差直接就是答案候选），要么找 `> pre[r]` 的最小余数（模 p 绕一圈）。历史余数放进 `set`，每次 `lower_bound` 即得，O(n log n)。

**核心**："前缀和之差"取模后有两种方向的最近邻——这就是[集合的 lower_bound](./2026-08-16-stl-ordered-containers)与前缀和的合体。

## 五、山峰函数的累计伤害（牛客寒假营 5 I）

> **题意**（[牛客寒假营 5](https://ac.nowcoder.com/acm/contest/120565) I「智乃挖坑」）：依次施法，第 i 次在位置 p_i 叠一座山峰 `max(0, f_i − |j − p_i|)`。问最早在第几次施法后，存在某位置的**累计**高度超过 h。

每次施法是一座"折线山"，天然分段线性。二分答案（第 k 次施法后是否超标），check 里对前 k 座山用**两个差分数组**分别维护"斜率 +1 的上升沿"和"斜率 −1 的下降沿"，前缀和两次还原出每个位置的累计高度；`__int128` 防溢出。

**核心**：分段线性函数的和仍是分段线性——差分一次变斜率、差分两次变"拐点计数"，这是"区间加"技巧对折线函数的直接推广。

## 六、奇数个圆覆盖（洛谷蓝桥国赛模拟 圆圈）

> **题意**（[洛谷蓝桥杯国赛模拟赛 2026](https://www.luogu.com.cn/contest/326698) D 圆圈，已对原题核对）：平面上 n 个圆（圆心、半径为整数，坐标域 ≤ 1000）。被**奇数个**圆覆盖的区域呈彩色（边界也算包含）。q 次询问给一个点，判断它所在区域是否彩色。

逐圆逐行做：圆心 y=h 的那一行，被覆盖的整数 x 是一段以弦长为宽的区间——用弦长公式算出半宽 dx（sqrt 后做整数微调防浮点误差），行内就是一次**区间 +1**。套路接龙：行差分 → 行前缀和 → 全图二维前缀和，最后 `cnt & 1` 判奇偶。

**核心**：几何题画出"每一行是一段区间"之后，剩下的就是纯差分模板；奇偶性把"数覆盖层数"变成"异或"。

## 小结

| 题 | 模型 | 一句话 |
|---|---|---|
| 周赛141 F | 二阶前缀和 | 数对贡献 = 个数前缀 × 下标前缀 |
| 周赛143 D | 扫描线 | 区间重叠 = ±1 事件排序求前缀和最大 |
| 周赛147 C | 环上差分 | 区间操作对"相邻差"只有端点处生效 |
| 寒假营5 E | 前缀和 + set | 模 p 的差找最近邻，两个方向都查 |
| 寒假营5 I | 双差分 | 折线函数的和还是折线 |
| 国赛 圆圈 | 二维差分 | 每行一段区间，奇偶即异或 |

前缀和家族的题面千变万化，但拆解到最后都是同一件事：**把"区间上的询问"换成"两个前缀状态的差"**。相关阅读：[双指针](./2026-08-16-two-pointers)、[并查集](./2026-08-16-dsu)。
