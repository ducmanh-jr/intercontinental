二分不是"一个算法"而是一个**问句**：判定结果随某个量单调变化吗？单调，就能二分。这份模板库按判定对象从具体到抽象排成一条线：数 → 方程根 → 答案 → 图 → 比率。

## 一、查找：lower_bound 的手写版（洛谷 P2249）

> **题意**（[查找](https://www.luogu.com.cn/problem/P2249)）：升序序列，多组询问 x 的最早出现位置，不存在输出 -1。

背下这套边界写法（左闭右开 + 三分支收敛），以后所有"查第一个 ≥ x"都不再犹豫：

```cpp
int lo = 1, hi = n + 1;          // [lo, hi)
while (lo < hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] >= x) hi = mid;   // 答案在左半（含 mid）
    else lo = mid + 1;
}
```

## 二、一元三次方程求根（洛谷 P1024）

> **题意**（[一元三次方程求解](https://www.luogu.com.cn/problem/P1024)）：ax³+bx²+cx+d=0 的三个互异实根（根之间差 ≥ 1），保留 2 位小数。

多项式连续，**相邻整数区间内至多一个根**（差 ≥ 1 保证）：扫 [−100, 100) 每个整区间 [i, i+1]，两端异号就在区间内实数二分到 1e-4。这是"连续函数 + 符号变化"的最小二分模型。

## 三、二分答案：最大化最小 / 最小化最大

> **题意**（[木材加工 P2440](https://www.luogu.com.cn/problem/P2440)）：n 段原木切出 k 段等长（只能整切），最大化段长。
> **题意**（[跳石头 P2678](https://www.luogu.com.cn/problem/P2678)）：起点到终点有 n 块石头，最多移走 M 块，最大化最短跳跃距离。

两题同一个骨架：**二分"每段长 ≥ d 能否凑够 k / 移走 ≤ M"，check 是 O(n) 顺扫**。边界图景见[贪心与二分](./2026-08-16-greedy-binary-roundup)里的判定边界图——✗ 在左 ✓ 在右，答案取第一个 ✓。

## 四、判定配合前缀和 / 差分

> **题意**（[借教室 P1083](https://www.luogu.com.cn/problem/P1083)）：n 天各有容量，m 份订单占 [s,t] 每天 d 间；问第一份无法满足的订单（前缀订单都要可行）。
> **题意**（[聪明的质检员 P1314](https://www.luogu.com.cn/problem/P1314)）：矿石 w、v，m 个区间 [l,r]；质检参数 W 下检验值 y = Σ(区间内 w≥W 的个数 × 价值和)，最小化 |y − s|。

订单满足**前缀性**（做到第 k 份可行 ⇒ 前 k−1 份也可行）→ 二分订单数，check 用**差分**把每份订单区间加 O(1) 完成。质检员二分 W：y 随 W **单调不增**，check 用满足条件的**个数前缀和与价值和前缀和**。两个题的共同点：**判定比求解便宜一个量级**——这正是二分答案该出场的信号。

## 五、图上二分：网格连通判定（洛谷 P1902）

> **题意**（[P1902](https://www.luogu.com.cn/problem/P1902)，形式化）：n×m 网格每格有高度；从第一行任意格走到第 n 行任意格（四连通），最小化路径经过的最大高度。

check(limit) = 只走高度 ≤ limit 的格子做 BFS，从整条第一行出发，问能否碰到第 n 行。高度上限单调 ⇒ 二分 limit。**判定函数可以是任何算法**（BFS/DFS/DP/贪心），二分只关心它的输出随 mid 是否单调。

## 六、实数二分：银行贷款（洛谷 P1163）

> **题意**（[银行贷款](https://www.luogu.com.cn/problem/P1163)）：借 w0，每月末还 w，共 m 个月还清，求月利率。

利率越高连本带利越还不清——check(利率) 模拟 m 个月复利判断能否还完，实数域二分 60~100 次即可收敛（精度 1e-6 级）。实数二分不纠结边界，纠结**循环次数与精度位数**的换算（每轮精度减半）。

## 七、01 分数规划：二分的终极形态

> **题意**（[POJ2976 Dropping tests](http://poj.org/problem?id=2976)）：n 门课成绩 a、满分 b，去掉恰好 k 门，最大化 Σa/Σb。
> **题意**（[P3199 最小圈](https://www.luogu.com.cn/problem/P3199)）：有向图最小平均权值的环。
> **题意**（[POJ2728 Desert King](http://poj.org/problem?id=2728)）：完全图上最小化 生成树 Σcost / Σ收益。

求比率的最优值？把答案 L 猜出来，做一个**形变**：

```text
Σa / Σb ≥ L  ⇔  Σ(a − L·b) ≥ 0 ⇔  g(L) = max Σ(a − L·b) ≥ 0
```

g(L) 随 L **单调递减**——又回到判定边界，只不过边界点是最优比率 L*。每轮二分把 a − L·b 当新权值，用各自领域的算法求 max：

## 小结

| 层级 | 题 | 判定 |
|---|---|---|
| 查找 | P2249 | 与 a[mid] 比较 |
| 求根 | P1024 | 端点符号 |
| 答案（整数） | P2440 / P2678 | O(n) 顺扫计数 |
| 答案（含差分/前缀） | P1083 / P1314 | 差分加 / 前缀和 |
| 图上 | P1902 | BFS 连通 |
| 实数 | P1163 | 复利模拟 |
| 比率 | POJ2976 / P3199 / POJ2728 | 各领域子问题 |

写二分题的检查清单就三条：**判定单调吗？check 够便宜吗？边界收敛方向对吗？**三条都答"是"，剩下的都是体力活。相关阅读：[贪心与二分](./2026-08-16-greedy-binary-roundup)、[数论小题](./2026-08-16-number-theory-roundup)（快速幂等工具）。
