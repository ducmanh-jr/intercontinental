刷牛客[新手入门 130 题](https://www.nowcoder.com/problem/tracker#/problems)时，栈文件夹是含金量最高的一个。这篇按难度递进把这七道题串成一条线——**栈的本质是"最近发生的还没配对的事"**。

## 一、括号匹配（栈的第一课）

> **题意**（[括号配对问题](https://www.nowcoder.com/practice/57260c08eaa44feababd05b328b897d7)：仅 `()` `[]`；[有效括号序列](https://www.nowcoder.com/practice/37548e94a270412c8b9fb85643c8ccc2)：`()[]{}` 三种）：判断括号串是否合法。

左括号是"欠债"，右括号是"还债"，还的必须是最**近**欠的那笔——所以左括号入栈，右括号查栈顶：类型匹配则弹出，不匹配或栈空则非法；扫完栈非空也是非法（还有债没还）。

## 二、吐泡泡（相邻消除）

> **题意**（[吐泡泡](https://www.nowcoder.com/practice/f86fa2221c094b3d8d1fc79bae450d96)）：串中相邻两个 `o` 合成一个 `O`，相邻两个 `O` 消除，连锁反应后输出结果。

仍是"栈配对"，但配对的对象会**升级**：与栈顶相同则弹出，但 `o` 弹 `o` 后要拿合成出的 `O` 继续和新栈顶比（可能连锁消）：

```cpp
for (char c : s) {
    while (!st.empty() && st.top() == c) {
        st.pop();
        if (c == 'o') c = 'O';   // 升级后继续比
        else { c = 0; break; }   // O 与 O 消掉了
    }
    if (c) st.push(c);
}
```

## 三、后缀表达式（逆波兰求值）

> **题意**（[牛牛与后缀表达式](https://www.nowcoder.com/practice/a1a4f178f6ff4188890e51da1cc8ce10)）：求形如 `1#2#+` 的后缀表达式值（数字以 `#` 结尾）。

后缀表达式天生无括号、无优先级，遇到运算符时**最近两个数**就是操作数——数字入栈，运算符弹两个算一个回栈，结束栈顶即答案。

## 四、中缀表达式（递归下降）

> **题意**（[表达式求值](https://www.nowcoder.com/practice/c215ba61c8b1443b996351df929dc4d4)）：求含括号与 `+ - *` 的中缀表达式值。

我们平时写的就是中缀，难点变成优先级和括号。递归下降的写法极短：`fun()` 从当前下标算出一个子表达式的值，遇 `(` 就递归自己；同一层里用**符号栈**处理乘法优先——`+` 把 num 入栈、`-` 把 −num 入栈、`*` 弹栈顶乘上再入栈，最后把栈里求和：

## 五、栈和排序（牛客原题）

> **题意**（[栈和排序](https://www.nowcoder.com/practice/b10a7ac681e9429e89a6a510e5799647)）：入栈顺序是 1..n 的某个排列，可在任意时刻出栈。求字典序**最大**的出栈序列。

预处理后缀最大值 `maxx[i]`（位置 i 之后还没入栈的部分的最大值）。每个数入栈后，只要**栈顶 > 后面所有还没入栈的数**，就立刻弹出——"此刻不出，后面再没有比它大的来救场"：

```cpp
for (int i = 1; i <= n; i++) {
    st.push(a[i]);
    while (!st.empty() && st.top() > maxx[i + 1]) { print(st.top()); st.pop(); }
}
```

## 六、最小栈（辅助栈）

> **题意**（剑指 Offer 30 / LeetCode 155 同款）：支持 push/pop/getMin 都 O(1) 的栈。

双栈设计：主栈照常；辅助栈只在 `新值 <= 辅助栈顶` 时同步压入，pop 时值相同则同步弹出。**相等也要压**，否则重复最小值被弹一次后就查不到了。

## 七、验证栈序列（能弹就弹）

> **题意**（[验证栈序列](https://www.nowcoder.com/practice/d3178fe362dd4810b577c77c9e128fc5)，LeetCode 946 同款）：给 push 序列和 pop 序列，判断是否可能是同一栈的合法操作。

按序把 pushed 压栈，每压一个就"**能弹尽弹**"——只要栈顶等于 popped 的当前期望就弹出。最终栈空即合法。为什么贪心正确：栈顶是唯一能立即响应期望的元素，此刻不弹以后更没机会。

## 小结

| 题 | 栈扮演的角色 |
|---|---|
| 括号匹配 | 欠债登记簿 |
| 吐泡泡 | 会升级的配对器 |
| 后缀表达式 | 操作数候补席 |
| 中缀表达式 | 优先级缓冲区 |
| 栈和排序 | 时机判断器 |
| 最小栈 | 双栈镜像 |
| 验证栈序列 | 贪心的执行者 |
