栈管"最近"，队列管"**先来先服务**"。牛客[新手入门 130 题](https://www.nowcoder.com/problem/tracker#/problems)的队列文件夹里藏着四道好题，从设计题一路刷到 NOIP 原题。

## 一、两个栈实现队列（设计题）

> **题意**（[用两个栈实现队列](https://www.nowcoder.com/practice/54275ddae22f475981afa2244dd448c6)，剑指 Offer 经典）：用两个栈实现队列的 push/pop。

入队压 stack1；出队时若 stack2 空，把 stack1 **整体倒**进 stack2 再弹。两次 LIFO 叠加 = FIFO。精髓在均摊：每个元素一生只被倒一次，n 次操作总代价 O(n)。

## 二、Dota 参议院（双队列轮转）

> **题意**（[参议院投票](https://www.nowcoder.com/practice/f334a81b22654efc8d7a67e31f60de50)，LeetCode 649 同款）：R/D 两派议员按座次轮流发言，发言着禁掉身后最近的敌人；被禁者跳过。求最后获胜方。

贪心：轮到的人一定禁掉**最近的**敌人（晚禁不如早禁）。实现用两个队列各存本派议员的**下标**，每轮弹出两队首比大小——下标小者本轮获胜，把自己以 `idx + n` 重新入队参与下一轮：

```cpp
while (!qr.empty() && !qd.empty()) {
    auto [r, d] = {qr.front(), qd.front()}; qr.pop(); qd.pop();
    (r < d ? qr : qd).push((r < d ? r : d) + n);   // 胜者进入下一轮
}
```

**核心**：队列天然表达"轮到谁"；`+n` 的轮次偏移避免重新编号。

## 三、机器翻译（NOIP 2010）

> **题意**（[机器翻译](https://www.nowcoder.com/practice/45ecfecd83104f37a685016361be504c)）：内存只能存 M 个单词。逐个读文章，单词不在内存里就要查词典（计数 +1）并放入内存；内存满了先淘汰**最早进入**的。求查词典的总次数。

这就是 FIFO 缓存置换的雏形——队列 + 计数数组：

![机器翻译的 FIFO 淘汰](/starlight/images/blog/fifo-cache.svg)

```cpp
if (!in_mem[x]) {
    ans++;                        // 查词典
    if ((int)q.size() == M) { in_mem[q.front()] = 0; q.pop(); }  // 淘汰最旧
    q.push(x); in_mem[x] = 1;
}
```

**核心**：`in_mem` 标记数组和队列互为索引——队列负责顺序，数组负责 O(1) 存在性，这个组合后面在 BFS 里还会反复出现。

## 四、三明治（计数降维）

> **题意**（[无法吃午餐的学生数量](https://www.nowcoder.com/practice/2dac3d7567f741a88ec551caf907934d)，LeetCode 1700 同款）：学生排成一队循环取餐，三明治按栈序摆放；队首学生与栈顶类型相同才拿走，否则去队尾排队。问多少人吃不到。

模拟循环最坏 O(n²)。但换个角度：三明治的顺序**只对"还剩什么"有意义**——学生喜欢 0/1 的各有多少人才是状态。统计两类学生人数，顺序扫三明治栈，能配就减一，配不动即停：

```cpp
// cnt[0]、cnt[1] 是想吃两类三明治的学生数
for (char s : sandwiches) { if (cnt[s-'0'] == 0) break; cnt[s-'0']--; }
// 答案 = cnt[0] + cnt[1]
```

**核心**：循环队列问题先问"顺序到底影响什么"。不影响就压成计数，O(n) 收工。

## 小结

| 题 | 知识点 |
|---|---|
| 两栈实现队列 | 均摊倒腾 |
| Dota 参议院 | 双队列 + 轮次偏移 |
| 机器翻译 | FIFO 淘汰 = 缓存思想 |
| 三明治 | 循环模拟降维成计数 |

队列的题眼永远是"**顺序有意义吗**"：有意义就老实排队（BFS、拓扑排序同款），没意义就用计数把循环压扁。相关阅读：[栈特辑](./2026-08-16-stack-classics)、[BFS 刷题记](./2026-08-16-bfs-on-graphs)。
