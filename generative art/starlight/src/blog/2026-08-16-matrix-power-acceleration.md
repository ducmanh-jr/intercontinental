递推/DP 的转移是**线性**的时候，步数再大也不怕——有两种把它结构化加速的板斧。这篇用洛谷蓝桥国赛模拟的两道题把它们讲清楚。

## 一、玩具：从暴搜到矩阵快速幂（洛谷蓝桥国赛模拟，填空）

> **题意**（[洛谷蓝桥杯国赛模拟赛 2026](https://www.luogu.com.cn/contest/326698) A 玩具，填空，已对原题核对）：一个玩具由圆形区域排成**梯子形**——第一、三、五列各有 341799 个圆，第二、四列各有 2 个圆（相当于上下两条横档 + 三根长竖柱）。给每个圆填一个小写字母，**相切的两个圆不能都是元音**（a/e/i/o/u）。求方案数 mod 998244353。

我的提交文件里保留了完整的思维演进，正好一步步看：

**第一步（错误起点）**：26 叉 DFS 暴搜——每格 26 种字母，检查相邻约束。百万级的格子，直接放弃。

**第二步（状态压缩）**：其实每个圆**只关心两件事**：它是元音还是辅音（5 / 21 种填法），以及**它相切的邻居**是元音还是辅音。约束只依赖这 1 bit 的交界信息——把一条横线上 5 个圆的"元音模式"编成 5 位掩码，状态只有 2⁵ = 32 个。

**第三步（矩阵化）**：三根竖柱是**完全同构的长链**（341797 步相邻转移），每根柱子上"上下两端点的元音状态"转移是一个 2×2 的小矩阵的幂；上下两条横档贡献带权掩码求和。于是——

![状压转移与矩阵快速幂](/starlight/images/blog/matrix-power.svg)

```
竖柱相邻转移：A[s][t] = (s 与 t 同为元音) ? 0 : w[t]
341797 步 = A 的 341797 次幂，快速幂 ~19 次矩阵乘搞完
```

**核心**：`f(i+1) = A · f(i)` 型的线性递推，n 步 = A 的 n 次幂 = 快速幂 log n 次矩阵乘。配合"26 种字母坍缩成 1 bit 元音/辅音"的降维，指数级的搜索塌缩成 32³·log L。相关阅读：[坏掉的显示器](./2026-08-16-seven-seg-probability)（状压的另一面）、[数论六则](./2026-08-16-number-theory-roundup)里的扩域快速幂——**任何结合代数上的幂都能二分**。

## 二、商店：按花费分层的计数 DP（洛谷蓝桥国赛模拟）

> **题意**（同场 F 商店，已对原题核对）：n 种道具售价 a[i]，m 项活动 (x, y, k)：**支付 k 元把 x 号道具兑换成 y 号**。你一开始什么都没有——花 a[j] 买一件 j 号道具，再沿活动链兑换。对每个 i 求总花费 ≤ P、最终拿到 i 号道具的方案数（初始购买不同、或用到的活动序列不同即算不同方案），mod 998244353。

状态 `dp[u][c]` = 走到"商品 u、累计花费 c"的路径数，转移沿规则边 c → c+k。朴素做法每次转移找最小花费层像 Dijkstra 带堆，O(c log)——其实**不需要堆**：花费只增不减，**按 c 从小到大扫桶**天然就是拓扑序：

```cpp
for (int c = 0; c <= P; c++)
    for (规则 (x, y, k) ：c + k ≤ P)
        dp[y][c + k] += dp[x][c];     // 桶序即转移序，无需排序
ans[u] = Σ_c dp[u][c];
```

**核心**："分层代替堆"是 Dijkstra/分层图计数的常用替身——当边权都是**非负增量**且总域不大时，按权值扫桶的顺序就是合法转移顺序，代码短一个量级。这与最短路计数（边松弛时顺路累加路径数）是同一族技巧。

## 小结

| 题 | 暴力 → 正解 |
|---|---|
| 玩具 | 26 叉 DFS → 状压 32 态 + 矩阵快速幂 |
| 商店 | 每步找最小层 → 按花费分桶扫 |

两板斧的共同前提：**转移本身是线性的、无后效的**。看到"步数上天"（1e9、1e18 级别）先冷静——要么状态能压成矩阵（快速幂），要么转移顺序能靠值域分桶（分层）。真正的敌人从来不是步数，是转移里的非线性（max/min、背包容量……），那才是要另想办法的地方。
