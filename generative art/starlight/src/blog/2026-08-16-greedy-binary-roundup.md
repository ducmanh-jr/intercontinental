贪心题最怕"感觉对但说不清"。这篇用六道我做过的比赛题归纳两条主线：**交换论证**（换一换不会更差）和**影响量分析**（一次操作到底改变多少）。二分答案则是它们的近亲——把"最优值"变成"可行性判定"。

## 一、环上分糖（牛客周赛 142 D）

> **题意**（[牛客周赛 142](https://ac.nowcoder.com/acm/contest/133790) D）：n 人围成一圈，第 i 人有 a_i 颗糖。每轮每个人**必须**给下一个人 0 或 1 颗糖。问若干轮后能否让所有人糖数相同。

先判总和是否能被 n 整除，得均值 avg。设 x[i] 为 i 传给 i+1 的糖数（只能取 0 或 1），列出方程 `a_i - x[i] + x[i-1] = avg`，移项得：

```cpp
x[i] = x[i-1] + (a_i - avg);   // 环环相扣，x[1] 定了整条链都定了
```

所以**只需枚举 x[1] ∈ {0, 1} 两种断点初值**，沿环递推一遍，检查所有 x[i] 是否都落在 {0,1} 且首尾闭合。"环上的传递问题 → 断环成链 + 枚举断点初值"是非常经典的模型。

## 二、染色平均数（牛客周赛 144 C）

> **题意**（[牛客周赛 144](https://ac.nowcoder.com/acm/contest/134981) C）：数组被分成红蓝两组（规模 c0、c1，和 s0、s1）。一次操作选 i、j 使 a_i 减 1、a_j 加 1（数值可越分到组外？组内元素值变化）。问让两组**平均值相等**的最少操作次数，无解输出 -1。

不盯着操作过程看，直接算"目标状态离当前多远"：两组均值相等等价于 `s0/c0 = s1/c1`，叉积差 `D = c0·s1 - c1·s0` 需要归零。而一次操作（一个数 -1、一个数 +1）最多让 |D| 变化 `n = c0 + c1`。于是答案就是：

```cpp
long long D = (long long)c0 * s1 - (long long)c1 * s0;
cout << (D % n == 0 ? abs(D) / n : -1);
```

**核心**：不模拟操作，而是给"差距"找一个一次操作最多改变固定量的势函数，答案 = 势差 ÷ 单步影响量。

## 三、二分答案配对（蓝桥杯多校模拟赛一 F）

> **题意**（[蓝桥杯多校模拟赛](https://ac.nowcoder.com/acm/contest/130226) F）：两个数组 l（n 个）与 r（m 个），把较少一方的元素全部与另一方配成对，最小化各对**差的最大值**。

"最小化最大值"是二分答案的标准信号。二分一个上限 d，判定"能否两两配对使每对差 ≤ d"：将两个数组排序后**双指针贪心**——l 与 r 中较小的那个必须立刻配掉（否则浪费），不配就再也没机会：

```cpp
// check(d)：两指针顺次扫，能配则配，否则移动较小者
while (i < n && j < m) {
    if (abs(l[i] - r[j]) <= d) { cnt++; i++; j++; }
    else (l[i] < r[j]) ? i++ : j++;
}
return cnt == min(n, m);
```

二分的过程，就是在答案轴上找 ✓/✗ 的分界：

![二分答案：找第一个可行的 d](/starlight/images/blog/binary-search-boundary.svg)

**核心**：判定函数里"较小者必须现在配"就是交换论证——交换论证在二分 check 里出现率极高。

## 四、堆维护前缀 top-K（洛谷蓝桥省赛模拟 E）

> **题意**（[洛谷蓝桥杯省赛模拟赛 2026](https://www.luogu.com.cn/contest/314564) E）：n 个矿井排成一排，走到第 i 个矿井要付前缀路费；手里的 m 元除了路费还能按 1 元/份收矿石，但最多选 K 个矿井开采。求最大采矿量。

枚举"走到第 i 个矿井"作为终点（路费是前缀和，定了终点路费就定了），剩余的钱能买 `min(m - cost_i, sum)` 份——其中 sum 是前 i 个矿井里**最大的 K 个产量之和**。从左往右扫，用小根堆动态维护前 K 大：

```cpp
for (int i = 1; i <= n; i++) {
    heap.push(a[i]); sum += a[i];
    if ((int)heap.size() > K) { sum -= heap.top(); heap.pop(); }
    ans = max(ans, min(m - prefix[i], sum));
}
```

**核心**："枚举一个维度 + 数据结构维护另一维度"是把 O(n²) 降到 O(n log n) 的常规路径，滑动 top-K 用小根堆最省事。

## 五、电梯调度（洛谷蓝桥省赛模拟 F）

> **题意**（同场 F）：n 个楼层请求（楼层 f_i、人数），电梯容量 W，从 X 楼出发把所有人送上顶楼 Y，求最短移动距离。

按楼层升序逐层处理：整批人贡献 `2(Y - f)`（送上去再回来）；不满一车的余数 r > 0 时顺路捎到下一层；**最后一趟不用返程**。贪心框架简单，但整车/余数/末层的分支特别多——这类题的教训是：**先把贡献公式写成几种情况，再统一进循环**，不要在循环里临时打补丁。

## 六、整除序列"能选则选"（牛客周赛 142 C）

> **题意**（[牛客周赛 142](https://ac.nowcoder.com/acm/contest/133790) C）：从数组里选最长的子序列，使第 k 个被选的数是 k 的倍数。

扫一遍，维护"下一个需要的除数" idx，遇到能整除的就选、idx++。正确性一句话（交换论证）：**若最优解跳过了当前可选的数，把它换进来不会让后面更差**——早满足的小指标不会挤占大指标的机会。

## 七、下移 y 坐标最小化距离和（牛客寒假营 6 A）

> **题意**（[牛客寒假营 6](https://ac.nowcoder.com/acm/contest/120566) A）：n 个点，共 w 次机会，每次把某个点的 y 坐标减 1（不能低于 0）。最小化最终所有点到原点的距离之和。

每次机会给谁？当然是给"下移一步收益最大"的点——用堆维护每个点再降 1 格的收益 `sqrt(x²+y²) − sqrt(x²+(y−1)²)`，每次弹堆顶、用掉一格、重算收益回堆。这个贪心**为什么对**：把每个点"第 1 次、第 2 次……下移的收益"排成一列，`sqrt` 的形状保证这列数**严格递减**（y 越低，再降一格省得越少）；于是全局问题变成"从 n 条递减序列里共选 w 个数，最大化总和"——每次取堆顶显然最优。

**核心**：可拆分的预算 + 凸的边际收益 → 堆贪心；写题时先在草稿上画一眼收益曲线的凸性再动手。

## 小结

| 题 | 套路 |
|---|---|
| 周赛142 D 环上分糖 | 断环成链，枚举断点初值 |
| 周赛144 C 染色平均数 | 势函数 ÷ 单步影响量 |
| 多校一 F 配对 | 二分答案 + 双指针判定 |
| 省模拟 E 采矿 | 枚举终点 + 小根堆 top-K |
| 省模拟 F 电梯 | 按情况写贡献公式再统一 |
| 周赛142 C 整除序列 | 能选则选 + 交换论证 |
| 寒假营6 A 下移坐标 | 递减边际收益 + 堆贪心 |

贪心不是玄学：写题前先问自己"**怎么换不会更差**"或"**一步到底改变多少**"，能回答其一，这份贪心才敢交。相关阅读：[构造题的两个直觉](./2026-08-16-construct-two-instincts)。
